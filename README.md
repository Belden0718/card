# 💳 卡友聰明刷 - 4大信用卡消費回饋即時決策器

專為解決台灣信用卡「**天天換權益**」、「**特殊通路0%排除**」、「**回饋封頂上限**」痛點設計的即時決策工具。

針對你手中的 **4 大主力神卡** 量身打造：
1. **國泰世華 CUBE 卡**（集精選 3%~3.3% / 樂饗購 3.3% / 玩數位 3.3% / 趣旅行 3%~3.3% / 慶生月最高 10% 小樹點無上限）
2. **台新銀行 Richart 卡**（原 @GoGo / 太陽 / 玫瑰卡 7+1 大刷：天天刷 3.8% / Pay著刷 3.8% / Chill刷手搖燒肉 10% / 數趣網購 3.3% / 玩旅海外 3.3%）
3. **永豐銀行 SPORT 卡**（汗水不白流 / DACARD 達標 + Apple / Google / Samsung Pay 感應最高 7% 豐點，月刷 $6,000 封頂）
4. **永豐銀行 DAWAY 卡**（LINE Pay 國內新戶 3% / 舊戶 1.5% LINE POINTS，海外最高 3%）

## ⚡ 核心功能

### 1. ⛽ 加油與 🏪 超商「秒選最佳卡片」
- **加油場景**：
  - 中油加油站：首選 **永豐 SPORT 卡**（Apple Pay / Google Pay 感應 **7%**）或 **台新 Richart 卡**（切換【天天刷】或【Pay著刷】出示 LINE Pay / 台新Pay **3.8%**）。
  - 若已切換 CUBE「集精選」，享中油直營 **3.3%** 小樹點無上限！
- **超商場景（7-11 / 全家）**：
  - 避免 0% 地雷！首選 **永豐 SPORT 卡**（Apple Pay / Google Pay 感應 **7%**）。
  - 次選 **台新 Richart 卡**（切換【Pay著刷】或【天天刷】出示「台新Pay」掃碼 **3.8%**，超商限單筆 $3,000）。
  - 備選 **國泰 CUBE 卡**（切換至「集精選」實體感應 **3%** 無上限）。

### 2. 💡 國泰 CUBE & 台新 7+1 權益切換動態提示
- 當你選取「中油加油」或「7-11」，但當前方案非「集精選」時，系統會跳出高亮提醒：
  > *「提示：只要在今天 23:59 前切換為【集精選】，回饋可從 0% 直接飆升至 3.0%~3.3% 小樹點無上限！」*
- 針對手搖飲與燒肉名店，系統會動態提示一鍵切換台新【Chill刷】拿 **10%** 狂暴回饋！
- 支援一鍵快速模擬切換測試。

### 3. ⚠️ 關鍵防雷與避坑指南
- **7-11 地雷**：7-11 門市的 LINE Pay **不支援永豐信用卡**扣款！請勿使用 DAWAY 綁 LINE Pay。
- **超商 0% 地雷**：超商屬於非一般消費，**千萬不要拿台新卡直接實體刷卡感應（0%）**！必須出示台新Pay掃碼。
- **中油地雷**：在中油刷台新卡請務必出示 **LINE Pay / 台新Pay**（3.8%），實體插卡僅 0.5%！
- **全聯 0% 地雷**：全聯僅 **國泰 CUBE 卡（切換集精選 3%）** 有回饋，其餘三張卡直接刷卡皆為 0% 排除！

### 4. 💰 消費金額即時試算機
- 輸入預計消費金額（例：$1,000 元），系統即時算出 4 張卡分別可獲得的點數/現金回饋。

## 🚀 啟動與使用方式

本專案採用 **Vite + React + TypeScript + Tailwind CSS** 開發，手機版介面極度滑順，可直接加入手機主畫面（PWA 體驗）。

### 1. 本地啟動開發伺服器
```bash
npm run dev
```
啟動後在瀏覽器開啟 `http://localhost:5173`。

### 2. 打包正式版本
```bash
npm run build
```
產生靜態檔案於 `dist/` 目錄，可直接部署至 GitHub Pages、Vercel、Cloudflare Pages 或 Netlify。
